# Daily Execution Workflow (Manual)

## Pre‑Trade Checklist (5 min)
- Market regime (trend / range / high volatility)
- Liquidity check (spreads + order book depth)
- News/events in next 24h
- Risk limits OK (daily loss, max exposure)
- Strategy signal confirmed (which strategy, why now)

## Before Order
- Entry price, stop, target set
- Position size in quote currency
- R/R acceptable (at least 1.5R)
- Order type decided (limit/market)

## After Order
- Record fill in journal (fills.csv)
- Note any slippage/fees surprises
- Mark rules followed? yes/no

## End of Day
- Update daily report
- Log lessons + adjustments
